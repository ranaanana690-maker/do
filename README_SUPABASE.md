# 🛡️ دليل ربط Supabase وإعداد لوحة التحكم الإدارية (Supabase & Admin Dashboard Setup Guide)

يقدم هذا الدليل خطوة بخطوة كيفية ربط المشروع بخدمة **Supabase** (قاعدة البيانات وخزينة الملفات)، وتنفيذ سياسات الأمان (RLS)، بالإضافة إلى إنشاء حساب الآدمن وتأمين اللوحة.

---

## 1️⃣ الخطوة 1: ضبط متغيرات البيئة (Environment Variables)

قم بفتح ملف `.env` في جذر المشروع وضع قيم مشروعك في Supabase:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

*يمكنك الحصول على هذه القيم من لوحة تحكم Supabase الخاصة بك عبر: **Project Settings ➔ API**.*

---

## 2️⃣ الخطوة 2: تنفيذ سكربت قاعدة البيانات والأمان (SQL Schema)

1. افتح لوحة تحكم [Supabase Dashboard](https://supabase.com/dashboard).
2. اختر مشروعك ثم اذهب إلى قائمة **SQL Editor** من الشريط الجانبي.
3. افتح ملف **`supabase_schema.sql`** الموجود في جذر هذا المشروع وانسخ محتواه بالكامل.
4. ألصق الكود في SQL Editor في Supabase واضغط على زر **`Run`**.

> **ما الذي يفعله هذا السكربت؟**
> - ينشئ جدول `housing_requests` لحفظ بيانات الطلاب.
> - يفعّل سياسات RLS المحصّنة (السماح للجمهور بالإدخال فقط `INSERT` والقراءة للأدمن الموثوق فقط `SELECT`).
> - ينشئ خزانة الملفات `housing_pdfs` ويقيد رفع الملفات بـ **PDF فقط** وبحجم أقصى **5MB**.

---

## 3️⃣ الخطوة 3: إغلاق إمكانية إنشاء حسابات جديدة (تعطيل Public Signups)

⚠️ **خطوة أمنية حاسمة لمنع الاختراق**:
1. اذهب في Supabase Dashboard إلى: **Authentication ➔ Providers**.
2. اضغط على خيار **Email**.
3. ابحث عن خيار **`Allow new users to sign up`** وقم **بإلغاء تفعيله (OFF/Disable)**.
4. احفظ التغيرات.

*هذا يضمن عدم قدرة أي متطفل من خارج المنظمة على إنشاء حساب آدمن عبر الـ API.*

---

## 4️⃣ الخطوة 4: إنشاء حساب الآدمن الأول (Create Admin Account)

لإنشاء حساب الآدمن الذي ستدخل به إلى لوحة التحكم:
1. اذهب في Supabase Dashboard إلى: **Authentication ➔ Users**.
2. اضغط على زر **`Add User`** ثم اختر **`Create User`**.
3. أدخل البريد الإلكتروني للآدمن (مثال: `admin@mascara-services.dz`) وكلمة المرور القوية.
4. تأكد من تفعيل خيار **`Auto Confirm User`**.
5. اضغط **Create User**.

---

## 5️⃣ الخطوة 5: تشغيل المشروع وتجربة لوحة التحكم

1. تشغيل التطبيق محلياً:
   ```bash
   npm run dev
   ```
2. رابط تقديم الطلاب (الصفحة العامة): `http://localhost:3000/`
3. رابط تسجيل دخول الإدارة: `http://localhost:3000/admin/login`
4. رابط لوحة التحكم المحمية: `http://localhost:3000/admin`

---

## 🔒 المميزات الأمنية المطبقة في النظام:
* **روابط تحميل مؤقتة وآمنة (Signed URLs)**: تنتهي صلاحية رابط استعراض PDF تلقائياً بعد 60 ثانية لحماية وثائق الطلاب.
* **الحماية من تعارض واستبدال الملفات (UUID Naming)**: تُسمى الملفات المرفوعة بأسماء فريدة باستخدام `crypto.randomUUID()`.
* **منع التكرار ووميض الشاشة (Bulletproof Guard)**: تستخدم صفحة الحماية `onAuthStateChange` للتحقق السلس من الجلسة ومنع أي ثغرة توجيه.
